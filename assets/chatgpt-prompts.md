# Prompts para generar imágenes con ChatGPT

Los dos prompts comparten la misma identidad visual que `icon.svg` y `social-preview.png`. Así, mezcles lo que mezcles, todo se ve de la misma familia.

> Consejo: los generadores de imágenes aún fallan con el texto (tildes, "¿", nombres). Si el texto sale mal, pide la versión **sin texto** y añade las letras tú después (Canva, Figma o Inkscape).

---

## 1. Imagen para el README (hero, 3:2 horizontal)

```
Flat vector illustration, wide landscape 3:2, for the README of an open-source tool called "ProfesorIA": a friendly digital teacher that sits next to a beginner programmer and explains, in short notes, the code they are building with AI.

Scene: a cozy desk at night seen from a slight angle. A laptop shows a few lines of real-looking code (Kotlin or Python, no "Hello World"). Floating beside the screen, a big amber speech bubble with the symbols "¿!" — the "oh, so that's all it was?" moment of understanding. Around the bubble, three small companion characters, each one a personality of the teacher:
1) a veteran mechanic with a wrench and rolled-up sleeves, relaxed, dry smile;
2) a young, warm vocational-school teacher with a small green graduation cap worn casually, laughing;
3) a wise, slightly sly video-game NPC wizard with a purple pointed hat and a tiny star.
They look curious and supportive, never strict. Small floating details: a "+1" badge, an unlocked padlock, a tiny arrow path A → B → C linking code blocks.

Style: clean flat vector, rounded shapes, soft geometric characters, no gradients, no glow, no 3D, no photorealism. Generous empty space on the left third for a title.
Palette (strict): background deep navy #141831, cards #1E2347, amber #FFB547, mint green #3DDC97, soft purple #7F77DD, off-white #F3F1EA.
Mood: playful, calm, encouraging, "learning while building".
Avoid: chalkboards with math formulas, stacks of books, stern professors, school classrooms, robots, neon cyberpunk, "Hello World", exam papers, clutter.
No text in the image except the "¿!" in the bubble.
```

## 2. Social preview de GitHub (1280×640, 2:1)

```
Flat vector banner, exact 2:1 aspect ratio (1280×640), GitHub social preview for an open-source Claude Code skill named "ProfesorIA".

Layout: left half reserved for the title — the word "ProfesorIA" in a bold rounded sans-serif, "Profesor" in off-white #F3F1EA and "IA" in amber #FFB547, with the subtitle below "Aprende a programar mientras construyes tu proyecto real." in off-white, the words "tu proyecto real" in mint green #3DDC97. Next to the title, the logo: an amber speech bubble with "¿!" in navy, a small mint-green graduation cap tilted on its top-left corner, and a tiny purple four-point star.
Right half: three rounded cards stacked vertically, each with a simple flat icon and a friendly character: a wrench (veteran mechanic, amber), a graduation cap (cool teacher, mint green), a wizard hat (video-game master, purple).

Style: clean flat vector UI-like illustration, rounded corners, subtle dot grid on the background, no gradients, no glow, no 3D. Keep 40 px safe margins on all sides; nothing important near the edges.
Palette (strict): background #141831, cards #1E2347, amber #FFB547, mint #3DDC97, purple #7F77DD, off-white #F3F1EA.
Mood: friendly, modern, encouraging, developer-tool aesthetic.
Avoid: chalkboards, math formulas, books, stern teachers, robots, neon, "Hello World", clutter, small unreadable text.
Text must be spelled exactly as given, including the inverted "¿". Do not invent extra words.
```
